数据并行 (Data Parallelism)

每张 GPU 持有完整模型副本，处理不同数据批次。训练后通过 AllReduce 同步梯度。

流量特征：AllReduce 通信，周期性同步突发，节点间流量大。通信反演可识别 Ring/HD/DBT 等具体算法。

张量并行 (Tensor Parallelism)

模型参数水平切分到多张 GPU，每层计算后通过 AllReduce 同步激活值。通常限制在同一节点内（NVLink）。

流水线并行 (Pipeline Parallelism)

模型按层切分为多个 Stage，数据像流水线流过各 Stage，相邻 Stage 通过 Send/Recv 同步。

专家并行 (Expert Parallelism)

MoE 模型中不同 token 路由到不同专家。通过 All-to-All 做 token 的跨 GPU 分发和收集。

3D 混合并行

节点内 TP（NVLink） + 节点间 DP（RoCEv2 AllReduce） + 跨 Pod PP（P2P）。反演算法需识别这些混合模式。

Broadcast（广播）

一个 GPU 将数据完整复制到所有其他 GPU。操作后所有 GPU 数据相同。

Scatter（散发）

一个 GPU 将数据分成 N 份，每份发给一个 GPU。各 GPU 拥有不同数据片段。

Gather（收集）

所有 GPU 将各自数据发送到一个目标 GPU。与 Scatter 相反。

Reduce（归约）

所有 GPU 数据经 SUM/MAX 等运算，结果只留在一个 GPU 上。

ReduceScatter（归约散发）

先按维度做 Reduce，再将结果 Scatter 到各 GPU。每个 GPU 获得一部分归约结果。AllReduce 的第一阶段。

AllGather（全收集）

所有 GPU 都获得所有 GPU 的数据。AllReduce 的第二阶段。

AllReduce（全归约）★

所有 GPU 数据做 Reduce 后，结果分发到所有 GPU。训练中最核心的原语。下面演示两种实现方式。

All-to-All（全交换）

每个 GPU 向其他所有 GPU 发送不同的数据片段，同时收集来自所有 GPU 的数据。区别于 AllGather（AllGather 各 GPU 收到相同数据）。

Send / Recv（点对点）

两个 GPU 之间的直接数据传输。流水线并行中相邻 Stage 之间传递激活和梯度。

Ring AllReduce 逐步演示

N 个 GPU 排成逻辑环，每个 GPU 只向右邻居发送、从左邻居接收。分 ReduceScatter（3 步）和 AllGather（3 步）两阶段。点击"下一步"逐步体验数据块在环上的传递和累加。

通信量：单 GPU 总量 = 2×(N-1)×AllSize/N ≈ 2×AllSize，与 GPU 数量无关。
