# 业务映射：AIGC3.0_RoCE流路径交互原型

## 1. 本原型对应的任务类型

- **输出归类**：正式交付物 / 交互原型
- **所属主线**：AIGC / AI Job / RoCE 流路径专项
- **输出位置**：`Knowledge/AI Job/`

---

## 2. 页面架构与导航路由

本原型包含四个独立 HTML 页面，对应如下用户旅程：

```
home.html（智能算网首页）
  └─→ index.html（AI任务分析 · RoCE流路径查询列表）
        └─→ flow-detail.html（流路径详情 · 独立页）
              └─→ fault-diagnosis.html（故障一键诊断）
  └─→ fault-diagnosis.html（故障一键诊断 · 从首页快捷入口直达）
```

| 页面 | 路由/文件 | 功能定位 |
|---|---|---|
| `home.html` | 智能算网首页 | 全局拓扑概览、告警分布、设备/AI任务资源概览、快捷入口 |
| `index.html` | AI任务分析 → RoCE流路径 | 流路径查询、列表展示、整体指标趋势 |
| `flow-detail.html` | 流路径详情 | 单条流的拓扑、指标趋势、告警热力图、下钻分析 |
| `fault-diagnosis.html` | 故障一键诊断 | 诊断任务管理、树图分析、新增检测任务 |

---

## 3. 用户旅程到页面结构映射

### 主线旅程

1. **智能算网首页（home.html）**
   - 全局 RoCE 调度平面拓扑（Core → Spine → Leaf → Server 层级）
   - 告警总数与严重/次要/警告分布饼图
   - 设备资源表格（NCP / NCF / ServerLeaf / Spine / 核心等）
   - AI任务资源表格（RoCE流数量、服务器总数、网卡总数、GPU总数、Leaf设备总数）
   - 快捷操作入口：AI任务分析 / 故障一键诊断 / 热点流路径 / 异常复盘

2. **RoCE流路径查询（index.html）**
   - 顶部一级导航（分析保障）+ 二级菜单（AI任务 / 故障一键诊断）
   - 查询过滤区：自定义起止时间 / 最近1h/4h/12h/24h 快捷 / 租户下拉 / 五元组（源IP/源端口/目的IP/目的端口）
   - 查询范围约束：最大查询区间 7 天，历史留存 7 天
   - 整体指标趋势看板：6项指标（吞吐/时延/抖动/丢包/PFC/ECN）汇总趋势
   - 流路径列表：含状态标识、告警摘要（严重/错误/警告数量Pill）、租户、最近活跃时间
   - 列表操作：「查看详情」跳转 flow-detail.html；「诊断」跳转 fault-diagnosis.html

3. **流路径详情（flow-detail.html）**
   - 详情标题与流快照（源/目的 IP 端口可视化连接图）
   - **概览与拓扑** 页签：路径拓扑 SVG（主路径 / 路径上下文 / 设备流量 三种模式切换）+ 匹配流的设备列表（可展开，含入/出方向接口、数据包、字节数）
   - **详细指标趋势** 页签：6项指标趋势图（支持按节点/接口精细筛选）
   - **告警记录** 页签：告警热力图（按服务器/交换机/下联接口分组，48个时间槽，颜色区分严重度）+ 支持点击时间槽进入**下钻分析面板**
   - 下钻分析面板（Drilldown Panel）：时间轴选择、指标摘要（端口Down数/PFC次数/队列超限次数/最大队列延迟/丢包率/ECN包数）、PFC趋势图、ECN趋势图、队列长度视图（多端口曲线+数据统计表+展开详情）、队列延迟占比视图

4. **故障一键诊断（fault-diagnosis.html）**
   - 诊断任务列表（左栏）：支持关键词搜索、已有历史任务展示
   - 诊断摘要卡（右栏上方）：任务名称、类型、时间范围、状态、异常项数
   - 诊断树图分析（右栏下方）：从诊断类型出发，展示 PFC/接口丢包/错包/网卡/ECN 等各节点结果
   - 新增检测任务弹层：任务名称、起止时间、诊断类型（训练中断/性能下降/训练卡死）、目标流选择

## 4. SRS能力到原型模块映射（完整版）

### 4.1 查询与过滤能力

| SRS / 需求能力 | 原型模块 | 说明 |
|---|---|---|
| 基于五元组查询流路径 | 查询过滤区 | 源IP、源端口、目的IP、目的端口均支持过滤 |
| 基于时间范围查询流路径 | 时间选择器 + 快捷时间按钮 | 自定义起止时间 + 最近1h/4h/12h/24h |
| 基于租户查询流路径 | 租户下拉 | 支持全部租户 + 单租户筛选 |
| 单次查询区间限制（≤7天） | 查询区时间校验 | 超限时提示并禁用查询按钮 |
| 历史数据留存说明 | 查询区标识提示 | 说明文案 + 信息图标气泡 |
| 无匹配结果展示 | 空状态区域 | 列表为空时展示空态提示 |
| 流路径状态筛选 | 列表区状态筛选 Tab | 全部 / 正常 / 告警 / 严重 |

## 6. 视觉风格映射

## 7. 本原型的评审价值

1. 可用于演示 `RoCE流路径管理` 从首页到详情、再到诊断的完整主旅程闭环
2. 可用于评审**流路径列表 + 详情**页面信息架构是否满足 SRS
3. 新增首页对于验证"全局资源概览 + 快捷跳转"能力的评审价值
4. **告警热力图 + 下钻分析**可评审是否满足时间槽级别的细粒度分析需求
5. 可作为后续补充诊断规则、接口字段和多租户权限模型的讨论底板
6. 流详情页独立化（flow-detail.html）对比旧方案抽屉设计，可评审大屏信息密度与导航一致性
